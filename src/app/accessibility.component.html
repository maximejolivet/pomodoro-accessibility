Accessibilité

L'accessibilité n'est pas optionnelle

Pomodoro TDAH est conçu pour fonctionner avec vous, quelle que soit votre façon d'interagir avec l'écran.

Comment Pomodoro fonctionne pour vous

⌨

Clavier seul

Naviguez complètement sans souris.

  • Tab entre les éléments
  • ← → changer d'onglet
  • PageUp PageDown ajuster le cadran
  • Esc fermer les modales
  • Focus toujours visible
🔊

Lecteur d'écran

NVDA, JAWS, VoiceOver, TalkBack, tout fonctionne.

  • Annonces vocales en temps réel
  • Labels et descriptions complets
  • Arborescence HTML sémantique
  • Régions ARIA pour les mises à jour
  • Métadonnées accessibles
👁

Visuel & Contraste

Lisible pour tous, peu importe la vue.

  • Contrastes 4.5:1+ (WCAG AA)
  • Mode sombre intégré
  • Pas de dépendance couleur seule
  • Police OpenDyslexic optionnelle
  • Texte bien espacé et dimensionné
🏗

Structure claire

Tout est organisé de façon logique.

  • HTML sémantique (heading, section, main)
  • Arborescence heading h1 → h2 → h3
  • Landmarks explicites
  • Navigation prévisible
  • 7 langues (FR, EN, ES, DE, IT, PT, AR)
💚

Confort neurodiversifié

Calme, prévisible, sans surcharge.

  • prefers-reduced-motion respecté
  • Interface sobre et TDAH-friendly
  • Pas de clignotement ou animation forcée
  • Pauses intégrées (Pomodoro = structure)
  • Retours visuels clairs

Standards respectés

Pomodoro TDAH respecte RGAA 4.1 (France) et WCAG 2.1 AA (International).

11 critères RGAA s'appliquent directement. Les critères 2, 10, 14, 15+ concernent documents, vidéos, et contenus externes.

✓ Images ✓ Couleurs ✓ Multimédia ✓ Tableaux ✓ Liens & Boutons ✓ Scripts & Clavier ✓ Éléments obligatoires ✓ Structuration ✓ Formulaires ✓ Navigation ✓ Consultation

L'accessibilité est intégrée dans chaque ligne de code de Pomodoro TDAH.

Pour le détail complet du RGAA 4.1, consulte le référentiel officiel : accessibilite.numerique.gouv.fr
